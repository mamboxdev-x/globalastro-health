GLOBALASTRO HEALTH — CREW HEALTH SYSTEM
=======================================

Cette archive contient le frontend React/TypeScript du prototype GlobalAstro Health.
Elle ne contient volontairement ni backend, ni base de donnees, ni API,
ni connexion a de vrais capteurs. Toutes les valeurs et courbes sont
fictives et servent uniquement a illustrer l'interface.

Site en ligne : https://www.globalastro.health


LANCEMENT SOUS WINDOWS
----------------------
1. Installer Node.js 22 (ou une version compatible avec Vite 8).
2. Ouvrir PowerShell DANS LE DOSSIER QUI CONTIENT package.json
   (c'est l'erreur la plus frequente : « Could not read package.json ... ENOENT »
   signifie qu'on est dans le mauvais dossier).
3. Executer :

   npm.cmd ci
   npm.cmd run dev

   Si Windows refuse « npm » :
     « Impossible de charger le fichier npm.ps1, car l'execution de scripts
       est desactivee sur ce systeme »
   -> utiliser npm.cmd au lieu de npm (un .cmd n'est pas soumis a la politique),
      OU une fois pour toutes, sans administrateur :
        Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

4. Ouvrir l'adresse locale affichee par Vite dans le navigateur.

Ne pas supprimer le dossier .figma : vite.config.ts en depend.


VERIFICATION
------------

   npm.cmd run typecheck
   npm.cmd run build
   npm.cmd run check


STRUCTURE
---------
src/App.tsx                       Navigation et structure generale
src/views/                        Les cinq ecrans du frontend
src/components/                   Composants partages
src/data/missionData.ts           Donnees de demonstration centralisees
src/context/DemoStateContext.tsx  Etats partages et sauvegarde locale
src/index.css                     Theme visuel (themes clair et sombre)


ETATS DE DEMONSTRATION
----------------------
Les validations d'exercices, cases de suivi et demandes simulees sont
conservees dans localStorage (cle « globalastro-demo-state-v1 ») lorsque le
navigateur autorise son utilisation. Elles ne sont jamais envoyees a un
service distant.

Les fichiers docs/ecran_*.png sont des captures du prototype ; elles peuvent
ne pas refleter exactement le theme CSS le plus recent.


CE QU'IL FAUT DIRE DEVANT LE JURY
---------------------------------
- Les indicateurs marques NON RENSEIGNE sont un CHOIX : l'outil refuse
  d'inventer une valeur. Ne pas les presenter comme un manque.
- Une banniere a l'ecran rappelle en permanence qu'il s'agit d'un prototype
  a donnees de demonstration : c'est une force, pas une faiblesse.
